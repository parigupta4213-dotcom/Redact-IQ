RedactIQ is a browser-based tool for finding and removing personal information from text. Your text is processed in your browser and is not uploaded to a server.

## Features

- Detects emails, phone numbers, IP addresses, PAN, Aadhaar, and credit card numbers.
- Choose full masking, partial masking, or consistent pseudonyms.
- Review detected text beside the sanitized result.
- Load a text or CSV file, then copy or download the result.
- Switch between light and dark themes.

## Run locally

Open `index.html` in a browser, or start a local server:

```bash
npm start
```

Then visit [http://localhost:8080](http://localhost:8080).

## Tests

```bash
npm test
```

Or open `tests.html` in a browser.
